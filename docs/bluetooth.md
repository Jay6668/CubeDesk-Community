# 蓝牙、协议与时间

本版一个适配器：`moyu32`，三阶。历史实测型号 MoYu 威龙 V10 AI；本次提取未做硬件验收。不要把同品牌、相似名称或扫描可见当成兼容保证。GAN、奇艺、二阶、计时器和开发板不在本版范围。

## 接口

`Link(on_event)` 暴露 `scan()`、`connect(opaque_scan_id, optional_mac)`、`disconnect()`、`refresh()`、`snapshot()`、`close()`。方法同步等待，I/O 在单独 asyncio 线程；UI 不操作 GATT。扫描只向 UI 返回临时标识、广播名和信号强度，不返回地址。地址/会话参数仅在内存。

连接前筛选广播；连接后必须确认服务与通知、写特征同时存在：

- 服务：`0783b03e-7735-b5a0-1760-a305d2795cb0`
- 通知：末尾 `5cb1`
- 写入：末尾 `5cb2`

只暴露 A1 初始化/信息、A3 状态请求、A4 电量请求。不提供绑定、重命名、复位、固件写入。UUID 和会话基础常量来自公开协议，不是账号密钥。

## 解码与事件

MoYu32 数据为 20 字节，使用会话 MAC 派生 AES-CBC 参数并处理重叠块；实现见 `moyu32.py`，MIT 参考及固定版本见第三方声明。A3 的 48 个三比特颜色加入中心后检查块方向、颜色数和排列奇偶性。A5 包含计数器及最近五个面转，按计数器确定增量，再从旧到新输出。

事件示例：

```json
{"kind":"move","move":"R'","seq":12,"epoch":4,"serial":17,"at":1234.56,"device_delta_ms":80,"time_source":"host_monotonic"}
```

`at` 是主机单调时钟秒；不是 UTC。`epoch` 隔离不同连接，`seq` 隔离重复事件。回绕 255→0 正常处理；重复或明显过期计数不推进。缺失超过五步或非法面转产生 `gap`，取消本局，重新请求基线，不拼出假完整记录。

同一数据包的多步先后顺序可靠，但基础版没有声称设备时间偏移已校准。该批使用相同接收时刻，标注 `host_batch`；原始偏移保留给开发者研究。计时精度受通知批量与传输延迟影响，不承诺等同硬件计时器。

状态基线只在会话建立/主动重同步时使用。后续相同计数状态只核对，不回放或覆盖正在转动的模型。异常输入计数通过 `parse_errors` 暴露；不记录原始包、MAC 或敏感日志。

## 生命周期与恢复

单连接、单通知订阅。重连先退订、断开并清理旧任务；订阅回调带连接 epoch。连接、服务与状态握手有超时。系统断连后取消练习，用户唤醒魔方后手动重新连接，不无休止后台重试。

Android 使用同一 Python 解析器，通过 JNI 调原生扫描/GATT/AES；包队列上限 2048，溢出使连接失效，避免默默丢步。Android 进入后台取消未完成练习，返回前台检查状态后重新开始。Windows 使用 Bleak 系统后端；系统蓝牙关闭会明确扫描失败。

新增协议请实现独立 Decoder 和连接特征描述，再注入平台 Scanner/Client。不要向计时/UI发送未经去重、排序和完整性判断的原始事件；补合成包、断连、重复订阅及实机测试，并提供来源许可。协议实现测试与实机验证必须分别记录。
