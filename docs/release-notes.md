# CubeDesk Community Edition 0.1.0

首次独立开源基础版本，面向学习和二次开发。沿用原项目的状态数学、打乱与WebGL经典/星钻渲染，提供MoYu32链路、准备/首转计时/首次复原停表/单次结果/独立本地记录，以及状态历史分析扩展入口。

自有源码MIT授权；第三方许可保留。Windows和Android共享Python核心，独立包名与数据。高级主题、额外皮肤、荣誉视频、档案、长期统计、题库、HID/开发板以及完整版私有历史不在本仓库。

Windows构建与原生窗口已验证，Android APK构建成功。22项自动化测试及经典/星钻真实WebGL演示流程通过。本轮没有连接真实魔方或Android设备，不把假GATT和浏览器尺寸测试当硬件验收。仅保留MoYu32，历史实测V10 AI，本轮提取后仍待复验；没有GAN/奇艺全型号兼容承诺。

提供的可执行文件是开发预览：Windows ZIP需整体解压，并需要系统WebView2；Android APK使用调试签名且独立安装，不覆盖正式版。源码含自行构建步骤。使用者应保留自己的数据备份，正式版下载与更新渠道不受本仓库影响。

更多见README、docs/building.md、docs/test-results.md和THIRD_PARTY_NOTICES.md。
