# 公开边界与隐私检查

本仓库从独立目录建立全新历史，不继承完整版 `.git`、分支或提交。原完整源和资源已先保存在私有备份，提取后逐文件哈希复核原源未变。正式版更新渠道未操作。

公开文件按清单扫描和人工检查：源码、网页、配置、文档、第三方声明、Gradle wrapper。排除生成输入、构建缓存、实际成绩库、日志、私人配置、设备抓包、媒体、证书和私钥。检查个人路径/账号/密钥模式和真实MAC；测试只用人工地址`02:00:00:00:00:01`。

MoYu32的BASE_KEY/BASE_IV是经MIT上游核对的公开协议参数，不是用户账号凭证。服务UUID同理。运行时真实地址只存内存，不写成绩、默认日志或仓库。

本机HTTP只监听127.0.0.1，校验Host/Origin，限制JSON请求长度、静态文件根路径；无远程更新、云接口、上传收款码或正式版资源读取。Android WebView仅访问自身本机源，文件访问关闭。

源码LICENSE、THIRD_PARTY_NOTICES和许可全文随发行物保留。调试APK是开发预览，不公开其私钥；Windows依赖WebView2。贡献者应自行检查新依赖和资源来源。

静态模式扫描不是形式化安全证明。未验证射频协议和特定OEM行为不应宣称通过；遇到未知来源资源应隔离，不先推送后删除。
